## ✨ Features

- 🚀 **Fast & Secure** - TOTP generation with industry-standard algorithms
- 📱 **QR Code Support** - Scan and display authentication QR codes
- 👥 **Multi-Account** - Manage unlimited 2FA accounts
- 🎨 **Theme Options** - Beautiful dark and light themes
- 🔔 **System Tray** - Minimize to tray for quick access
- ⚡ **Auto-Start** - Launch with Windows automatically
- 💾 **Import/Export** - Backup and restore your accounts
- ⭐ **Smart Features** - Favorites, notes, and one-click copy

## 📥 Installation

### Download Pre-built Binary

Download the latest release from the [**Releases**](https://github.com/tanmoythebot/totp-manager/releases) page.

Simply extract and run `TOTPManager-v0.0.1-win64.exe` - no installation required!

## 🛠️ Building from Source

### Prerequisites

```
Qt 6.7.0+
CMake 3.20+
MinGW (Windows) / GCC/Clang (Linux)
```

### Build Instructions

```bash
# Clone the repository
git clone https://github.com/tanmoythebot/totp-manager.git
cd totp-manager

# Build
mkdir build && cd build
cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build . -j4

# Executable will be in bin/ directory
```
